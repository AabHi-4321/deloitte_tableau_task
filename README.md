# # 🏭 Factory Equipment Health Analysis Dashboard
### Deloitte Data Analytics Virtual Experience (Forage) – Task 1

## 📌 Project Overview

This project was completed as part of the **Deloitte Data Analytics Virtual Experience Program** hosted on **Forage**.

The objective was to analyze factory equipment health data and build an interactive Tableau dashboard to help management identify factories and device types with the highest number of unhealthy machines.

---

## 🎯 Business Objective

The client wanted to identify:

- Which factory has the highest number of unhealthy devices.
- Which device types contribute the most to equipment health issues.
- Areas that require immediate maintenance and operational attention.

The dashboard enables quick identification of high-risk factories and equipment, supporting data-driven maintenance planning.

## 📈 Dashboard Features

### 1. Unhealthy Devices by Factory
- Displays the number of unhealthy devices across all factories.
- Helps identify factories requiring immediate maintenance.

### 2. Unhealthy Devices by Device Type
- Shows which equipment types contribute most to operational issues.
- Supports prioritization of maintenance activities.

### 3. Interactive Dashboard
- Selecting a factory filters the device-type chart.
- Enables users to explore equipment health by factory.

---

## 🔍 Key Insights

### Factory Analysis

- **Daikibo Factory Seiko** has the highest number of unhealthy devices.
- **Daikibo Shenzhen** is the second most affected factory.
- **Daikibo Berlin** has the fewest unhealthy devices.

### Device Analysis

- **Laser Welder** is the most unhealthy device type.
- **Laser Cutter** is the second highest contributor.
- Heavy Duty Drill contributes moderately.
- Other device types have relatively low unhealthy counts.

---

## 💼 Business Recommendations

- Prioritize maintenance at **Daikibo Factory Seiko**.
- Perform preventive maintenance on **Laser Welders** and **Laser Cutters**.
- Monitor Heavy Duty Drills to prevent further degradation.
- Establish routine health monitoring to reduce equipment downtime.

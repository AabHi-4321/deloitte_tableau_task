# 📖 Project Overview

This project was completed as part of the **Deloitte Data Analytics Virtual Experience Program** hosted on **Forage**.

The objective of this project was to analyze factory equipment health data and develop an interactive Tableau dashboard that helps management identify factories and machine types requiring immediate maintenance attention.

The dashboard transforms raw operational data into meaningful business insights, enabling data-driven decision-making and improving equipment maintenance planning.

---

# 🎯 Project Objectives

The primary objectives of this project were to:

- Analyze factory equipment health data.
- Identify factories with the highest number of unhealthy devices.
- Determine which device types contribute most to equipment failures.
- Build an interactive Tableau dashboard.
- Present business insights through effective data visualization.

---

# 📂 Dataset Information

The dataset used in this project was provided as part of the **Deloitte Data Analytics Virtual Experience Program**.

The dataset contains operational information about factory equipment, including:

- Factory Name
- Device Type
- Device Status
- Unhealthy Device Count

The data was analyzed using Tableau to generate meaningful visualizations and identify maintenance priorities.

# 📈 Dashboard Components

## 1️⃣ Unhealthy Devices by Factory

Displays the total number of unhealthy devices across different factories.

This visualization helps identify factories that require immediate maintenance attention.

---

## 2️⃣ Unhealthy Devices by Device Type

Displays the number of unhealthy devices by equipment category.

This helps management determine which machine types contribute most to operational issues.

---

## 3️⃣ Interactive Filtering

The dashboard supports interactive analysis.

Selecting a factory dynamically filters the device-type chart, allowing users to analyze equipment health for a specific factory.

---

# 🔍 Key Insights

### Factory Analysis

- Daikibo Factory Seiko recorded the highest number of unhealthy devices.
- Daikibo Shenzhen ranked second.
- Daikibo Factory Meiyo showed moderate equipment issues.
- Daikibo Berlin had the lowest number of unhealthy devices.

---

### Device Analysis

- Laser Welder is the most unhealthy equipment type.
- Laser Cutter is the second highest contributor.
- Heavy Duty Drill shows moderate maintenance requirements.
- Other equipment categories have comparatively fewer unhealthy devices.

---

# 💡 Business Recommendations

Based on the analysis:

- Prioritize preventive maintenance for Daikibo Factory Seiko.
- Schedule regular inspections for Laser Welders and Laser Cutters.
- Monitor Heavy Duty Drills to reduce unexpected failures.
- Implement periodic equipment health monitoring across all factories.
